Recommendations by Scenario
🧠
NLP / Generative AI
Language Understanding · Generation

Use GPT-4o when task complexity and output quality are the priority and compute cost is acceptable — enterprise content, multi-step reasoning, or multimodal workflows. Use BERT-base when deploying at scale with tight latency requirements: classification, semantic search, or NER where a fine-tuned encoder outperforms a large generative model at a fraction of the cost.

👁️
Computer Vision
Classification · Detection

Use MobileNetV3 for mobile, edge, or IoT contexts where inference must run in under 1ms with minimal memory. Use EfficientNetV2-L when accuracy is non-negotiable and GPU resources are available — medical imaging, defect detection, or fine-grained classification where the performance gap justifies the compute cost.

📊
Tabular Data
Structured · Interpretable

Use XGBoost as the default for regulated domains (fintech, healthcare) where SHAP-based explainability must satisfy compliance requirements. Use LightGBM when dataset size exceeds millions of rows or training speed is a bottleneck — it trains 10x faster with comparable accuracy and is the better fit for real-time production scoring pipelines.
